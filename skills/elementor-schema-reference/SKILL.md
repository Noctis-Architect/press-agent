# ساختار اسکیمای تایپ‌شده المنتور در PressAgent (Schema Reference)

سرور PressAgent MCP پیچیدگی‌های خام JSON المنتور را به یک **اسکیمای تایپ‌شده، اعتبارسنجی‌شده و ایمن** تبدیل کرده است. این سند نحوه نگاشت ورودی‌های هوش مصنوعی به ساختار ذخیره‌سازی المنتور را تشریح می‌کند.

---

## ۱. ضمانت‌های اعتبارسنجی سمت سرور (Server-side Guarantees)

سرور PressAgent پیش از هرگونه ذخیره‌سازی در المنتور، بررسی‌های زیر را اعمال می‌کند:

1. **شناسه‌ها (IDs):**
   - همه المان‌ها باید شناسه ۸ کاراکتری هگز (`[a-f0-9]{8}`) داشته باشند.
   - در صورت عدم ارسال شناسه توسط مدل، سرور به طور خودکار یک شناسه تصادفی هگز یکتا تولید می‌کند.
   - وجود هرگونه شناسه تکراری در کل درخت برگه بلافاصله شناسایی شده و مانع از خرابی رندر می‌شود.

2. **قوانین سلسله‌مراتب (Nesting Hierarchy):**
   - ویجت‌ها هرگز نمی‌توانند دارای المان فرزند (`elements`) باشند.
   - ویجت‌ها نمی‌توانند بدون کانتینر یا ستون در صفحه رها شوند.
   - کانتینرهای فلکس‌باکس بومی (`container`) کانتینرها یا ویجت‌های مجاز را در خود نگه می‌دارند.

3. **حفاظت امنیتی (Forbidden Widgets & Injections):**
   - ویجت‌های `html` و `shortcode` در سطح اسکیما و کدهای اعتبارسنجی مسدود هستند.
   - هرگونه تگ `<script>` یا `<style>` در متون متوقف می‌شود.

4. **تبدیل هوشمند ابعاد و فواصل:**
   - مقادیر توکن فواصل (`xs`, `sm`, `md`, `lg`, `xl`, `2xl`) توسط سرور به مقادیر معتبر پیکسلی آبجکتی المنتور (`{ unit: "px", size: ... }`) تبدیل می‌شوند.

---

## ۲. توکن‌های طراحی و نگاشت به کیت فعال (Design Token Resolution)

هنگام استفاده از توکن‌ها در ابزارهای MCP، سرور آن‌ها را به متادیتای گلوبال المنتور نگاشت می‌کند:

```
color: "primary"   --->   title_color: kit.colors.primary.value
                           __globals__: { title_color: "globals/colors?id=primary" }

gap: "lg"          --->   flex_gap: { unit: "px", size: 24, column: "24", row: "24" }

padding: "md"      --->   padding: { unit: "px", top: "16", right: "16", bottom: "16", left: "16", isLinked: true }
```

این رویکرد تضمین می‌کند که کدهای ایجاد شده توسط هوش مصنوعی با استایل‌های سرتاسری تم و کیت سایت یکدست بوده و توسط ادمین در پنل Elementor کاملاً قابل تنظیم و ویژوال باشند.
