# PressAgent Skills 🧠

این دایرکتوری شامل بسته‌های مهارتی (Skills) برای توسعه‌دهندگان و ایجنت‌های هوش مصنوعی (Antigravity و Claude) در اکوسیستم PressAgent است.

---

## ۱. اسکیل‌های بومی پروژه PressAgent (PressAgent Native Skills)

این مهارت‌ها به طور اختصاصی برای طراحی صفحات، بازرسی بصری و ادغام با MCP در این پروژه توسعه یافته‌اند:

| اسکیل | هدف و کاربرد |
|---|---|
| **`pressagent-elementor`** | ویرایش بومی، استاندارد و امن صفحات وردپرس با المان‌های المنتور، مدیریت کش و گیت تاییدیه کاربر. |
| **`elementor-design-system`** | الگوهای فلکس‌باکس کانتینر، جلوگیری از ستونی شدن کارت‌ها و تکنیک هیبرید HTML/CSS در المنتور. |
| **`elementor-visual-inspector`** | چرخه بازخورد بصری و تست خودکار با ابزار تصویربرداری مرورگر (`pressagent_capture_screenshot`). |

---

## ۲. اسکیل‌های مهندسی و توسعه (Engineering & Security Skills)

این اسکیل‌ها جهت ارتقای کیفیت کدنویسی پلاگین PHP، سرور MCP، ممیزی امنیتی و تست‌های یکپارچه‌سازی اضافه شده‌اند:

| اسکیل | کاربرد در PressAgent |
|---|---|
| **`wordpress-pro`** | الگوهای معماری پلاگین وردپرس، هوک‌ها و فیلترها، متدهای REST API و استانداردسازی کدها. |
| **`mcp-developer`** | استانداردهای ساخت سرور Model Context Protocol (TypeScript)، تایپ‌های ورودی/خروجی Zod و کنترل خطا. |
| **`php-pro`** | نگارش مدرن PHP 7.4/8.x، تایپ‌گذاری دقیق، بهینه‌سازی حافظه و استانداردسازی PSR. |
| **`secure-code-guardian`** | ایمن‌سازی ماژول‌های پرریسک از جمله `class-code-executor.php` (God Mode)، ضد XSS و SQL Injection. |
| **`security-reviewer`** | بازبینی دسترسی‌ها و کنترل سطوح RBAC Scopes در توکن‌های اعطا شده به هوش مصنوعی. |
| **`playwright-expert`** | تست‌های مرورگر بدون سر و تعاملات خودکار جهت تصویربرداری و تست عملکردی. |
| **`test-master`** | استراتژی‌های آزمون جامع، تست واحد (Unit Tests) و تست‌های یکپارچگی (Integration). |
